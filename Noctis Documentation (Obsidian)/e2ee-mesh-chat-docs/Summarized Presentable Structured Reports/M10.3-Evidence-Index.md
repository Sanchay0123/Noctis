## Evidence interpretation rules

1. M10.2 performance numbers are local loopback measurements.
2. Relay blindness is supported by M9.1, not inferred solely from M10.2 latency data.
3. AEAD decryption performance is not measured.
4. Concurrent handshake scaling is not measured.
5. CPU utilization percentage is not measured.
6. 60 KiB is the largest tested payload, not an absolute protocol maximum.
7. `PacketID` is not globally unique; duplicate suppression uses `(source_node, packet_id)`.
8. M6 is bounded managed flooding, not a DHT or route-selection protocol.
9. No production security or protocol modifications were made for M10.2.
